How to install on the band

The Mi Fitness app only installs faces from Xiaomi's store. A proxy on your computer delivers your file instead of a store face while the phone downloads it.

  1. Create the file with Build .bin.
  2. In a terminal: python -m n69face install projects/<base>/<base>_custom.bin
  3. On the phone (same Wi-Fi): set a manual proxy with the computer's IP and port 8080.
  4. Open http://mitm.it on the phone, install the certificate and enable full trust (iPhone: Settings → General → About → Certificate Trust Settings).
  5. In Mi Fitness, install a free face you have never installed before.
  6. Afterwards: turn the proxy off on the phone and remove the certificate.

Unofficial modification, use at your own risk. If the band freezes, restart it and switch faces.
